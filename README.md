One sentence, one star for the planet, five stars for the food. This program
writes a single original sentence — an alien tourist's one-star review of
Earth that still compliments the food — to `/output/entry.txt`, and checks
it first: exactly one sentence, 1–200 characters, no line breaks.

> One star: your planet's gravity keeps stealing my luggage, the locals keep
> shouting at clouds, but the noodles alone are worth the crash-landing.

## Run it

```sh
python3 main.py
```

The entry is 145 characters, inside the 200-character limit.
